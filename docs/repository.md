# Repository layout

Commit Mono is published as a website that customizes and serves the font, and this
repository is that website plus the compiled font binaries the website customizes. There
are no font sources in the usual sense (no `.glyphs`, `.ufo` or `.designspace` files): the
binaries in `src/fonts/fontlab/` are the source of truth, and everything else is derived
from them. The `tools/` directory can decompile them into editable sources on demand.

## Top level

| Path | Role |
|---|---|
| `index.html` | The whole website as one page in ten sections. Loads the fonts, hosts the customize wizard, and defines `versionOfCommitMono` (`"V143"`), the tag that selects which binaries the wizard fetches. |
| `package.json`, `bun.lock`, `.nvmrc` | Vite project: `bun install`, `bun run dev`, `bun run build`. There is no `vite.config`; Vite serves the repository root, so the wizard's fetches of `/src/fonts/fontlab/*.otf` read the working tree directly. |
| `src/` | Website assets and the font binaries, described below. |
| `tools/` | Python tooling (`cmfont`) to extract, rebuild, verify and proof the fonts. See [building.md](building.md). |
| `docs/` | These pages. |
| `build/` | Generated by the tooling and ignored by git: extracted UFO sources, rebuilt fonts, proof sheets. |
| `LICENSE` | MIT, for the website code. |
| `LICENSE-FONT` | SIL Open Font License 1.1, for the fonts. It declares no Reserved Font Name, so modified builds may keep the name; the website's wizard already ships modified fonts named "CommitMono". |
| `404.html`, `manifest.webmanifest`, `favicon.ico`, `apple-touch-icon.png` | Site plumbing. |

## `src/fonts/`

| Path | Role |
|---|---|
| `fontlab/CommitMonoV143-<weight><style>.otf` | 42 static CFF OpenType fonts: weights 200 to 700 in steps of 25, each as Regular and Italic. Exported from FontLab 8 (the unique ID ends in `FL820`). These are what the wizard customizes. |
| `fontlab/CommitMonoV143-VF.ttf` | The variable font (TrueType outlines, `wght` 200–700 and `ital` 0–1). Shipped unmodified in the wizard's "design" download. |
| `fontlab/CommitMonoV143-VF.woff2` | The same variable font compressed for the website itself. |
| `CommitMono-1.143.zip` | The release archive attached to GitHub releases: the wizard's default download, converted to TrueType and hinted by the manual recipe in `src/txt/ttfautohint.txt`. |
| `other/*.woff2` | Other monospace fonts, used only by the website's comparison section. |

## `src/features/`

OpenType feature code (`.fea`) from the FontLab project: the ligature, arrow, smart case,
symbol spacing and smart kerning rules, plus scratch copies (`... copy.fea`, `test.fea`).
Nothing in the repository compiles these files, and they are not a complete or current
description of the binaries (for example there is no file for `cv09`). Treat them as design
notes. The authoritative description of the layout rules is the binary's GSUB table, which
[features.md](features.md) renders.

## `src/js/`

| Path | Role |
|---|---|
| `download_wizard.js` | The customize-and-download pipeline. It runs entirely in the browser with opentype.js: fetch the static OTF for each requested weight and style, swap glyph outlines for the chosen `cvNN` alternates, merge the chosen `ssNN` features into a synthesized `calt` feature so editors apply them without configuration, apply letter spacing and line height, rename the family to "CommitMono", and zip the result (four styles for a normal download, all 42 plus the variable font for the "design" download). |
| `website_data.js` | Content catalog for the site, including the list of customizable features with their tags, labels, descriptions, examples and defaults. `cmfont features` reads this so the generated reference uses the same wording. |
| `opentype.min.js`, `zip.min.js` | Vendored libraries used by the wizard. |
| Other files | One module per website section, plus navigation and utilities. |

## `src/txt/`

| Path | Role |
|---|---|
| `ttfautohint.txt` | The manual release recipe: download the default zip from the website, convert each OTF to TrueType with FontForge, hint with ttfautohint, zip. |
| `woff2_conversion_guide.txt` | How the variable font's woff2 was produced (Google's `woff2_compress`; `fonttools ttLib.woff2 compress` does the same). |
| `installation.txt`, `license.txt` | Included in every download. |
| `featuretest.txt` | Sample text exercising the features; `cmfont proof` renders it. |
| `todo.txt` | The author's task list. |

## Other directories

`src/css/` styles the website section by section, `src/tests/` holds ad-hoc HTML and JS
experiments for feature rules, `src/language_examples/` supplies the code samples shown on
the site, and `src/img/` holds site images.
